# Web3 Skills

A collection of skills for Web3 / EVM development and analysis.

## Available Skills

| Skill | Description |
|-------|-------------|
| [fetch-source](./skills/fetch-source/SKILL.md) | Fetch verified smart contract source code from Sourcify and Etherscan for any EVM-compatible chain |
| [trace_tx](./skills/trace_tx/SKILL.md) | Fetch full execution traces for EVM transactions via Alchemy's debug_traceTransaction API — call trees, revert reasons, gas usage, internal transfers |
